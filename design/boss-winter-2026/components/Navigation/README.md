The BOSS page chrome around the agenda: the nav row (Register, Schedule, Gallery, Go back to bitshala) and the season pills. This is the only place the bright accents appear.

`BOSS.html.nav()` · `BOSS.html.seasonPills(['Winter 2026', 'Summer 2026'], 'Winter 2026')` · `BOSS.html.heading(BOSS.schedule)`.

- **Nav links** are set in DX Slight: Register in `coral`, Schedule in `butter`, Gallery in `mint`. "Go back to bitshala" is a flat white `chip` button with `on-chip` text and no shadow.
- **Season pills:** the active one is a `highlight` block with `on-chip` text. Inactive pills have a `plum-900` fill and a `plum-500` outline.
- **Heading:** "Winter 2026 Agenda" in DX Slight Medium Tall, with "Agenda" on a `highlight` block. The block has extra room at the bottom so the descender of the g stays inside it.
