The outlined block that groups a half-day: "Session 03" on the left, the block's time range on the right, then its cards.

`BOSS.html.sessionBlock(number, sessions)`. The outline is a 2px `frame` border with `radius-lg`. Numbering runs across the whole summit (Day 02 holds Sessions 01–02, Day 03 holds 03–04, and so on). The range is worked out from the first card's start and the last card's end.
